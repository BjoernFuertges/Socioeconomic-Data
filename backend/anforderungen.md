# Anforderungen Backend
## Funktional
* Die Daten müssen in einem maschinenlesbaren Format zurückgegeben werden.
* Es muss eine Abfrage nach Gebiet möglich sein.
* Es muss eine Dokumentation der API-Endpunkte für technisch versierte Anwender geben.
* Es soll eine Abfrage von Geo-Tiles möglich sein.
* Es soll unterschiedliche *Metriken* zu einem Gebiet liefern.
* Es muss der Datenimport in das System möglich sein.
* Es kann eine Ermittlung von *Metriken* durch das System erfolgen.

## Nicht funktional
* Das System muss stabil laufen.
* Das System muss zuverlässige (= reproduzierbare) Ergebnisse erzielen.
* Das System soll kurze Antwortzeiten haben.
